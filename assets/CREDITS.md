# Asset credits

## Tiny RPG Forest

Artwork by Luis Zuno (@ansimuz)

License: Creative Commons Zero (CC0) / public domain
Source: https://opengameart.org/content/tiny-rpg-forest
Pack license file: licenses/ansimuz-tiny-rpg-forest.txt

Used in this project:

- Tileset and sliced forest objects
- Hero idle and walk sprites
- Gem sparkle frames

The Forest of Focus displays derived copies in
`derived/enchanted/`. Those files keep the original silhouettes
and recolor them toward emerald and jade vegetation, sandy paths,
cool stone, orchid blossoms, and turquoise crystals. The originals in
`environment/`, `objects/`, and `sprites/` are unchanged.
`scripts/derive-enchanted-forest.py` regenerates the copies.

Not used:

- Demo game code
- Combat / enemy sprites
- Music by Pascal Belisle (different license; requires credit if used)

## Kenney Roguelike/RPG pack

Evaluated (CC0, Kenney.nl). Not imported, so the Forest of Focus
keeps a single art style from the ansimuz pack.

## Original placeholders

On-screen joystick, sit button, sitting pose, fox location
marker, and Flick marker were drawn for this project.

Flick is a fictional forest character inspired by stories of
the Aluxo'ob from Yucatec Maya tradition. This playful
interpretation is not an authentic representation of Maya
spiritual beliefs or practices.
